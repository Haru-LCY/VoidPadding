Let [VOID] Handle Padding in Masked Diffusion Language Models so that [EOS] Can Focus on Semantic Termination

1

We systematically analyze the mechanism behind [EOS] overflow and show that it stems from the dual use of [EOS] for termination and padding during instruction tuning.

2

We propose VoidPadding, a training-inference co-design that decouples the two roles by using [VOID] for padding and reserving [EOS] for termination, enabling [EOS]Termination for early stopping and VoidExpansion for adaptive canvas expansion.

3

Experiments show that VoidPadding prevents [EOS] overflow, improves generation quality and decoding efficiency, and remains robust across block sizes and canvas lengths.

Separate emptiness from ending.

Repeated padding blurs the boundary between padded canvas and true response termination. VoidPadding gives those signals different tokens.

[VOID] for padding

Training uses a dedicated token for padded emptiness, giving the model a direct representation of unused response canvas.

[EOS] for meaning

Semantic termination stays assigned to [EOS], reducing pressure for the same token to encode padding and ending.

Inference stays clean

[VOID] generation is banned at inference while its probability becomes a useful signal for adaptive canvas expansion.

VoidPadding decouples padded emptiness from semantic termination in masked diffusion language models.
